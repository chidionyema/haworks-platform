## CRITICAL: Idempotency Violation in StartCheckoutCommandHandler

### CRITICAL: Broken Idempotency Logic
- **File**: src/CheckoutOrchestrator/CheckoutOrchestrator.Application/Commands/StartCheckoutCommand.cs:39-42
- **Issue**: When `IdempotencyKey` is null/empty, the code falls back to `Guid.NewGuid().ToString("N")`, generating a different saga ID on each retry
- **Impact**: Complete idempotency failure - retried requests with empty/null idempotency keys will create multiple sagas for the same logical checkout
- **Fix**: 
```csharp
if (string.IsNullOrEmpty(request.IdempotencyKey))
{
    return Result.Failure<StartCheckoutResponse>(
        Error.Validation("IdempotencyKey.Required", "Idempotency key is required"));
}
var hash = SHA256.HashData(Encoding.UTF8.GetBytes(request.IdempotencyKey));
```
