## Test Optimization Violations

### **[MEDIUM]**: Multiple Task.Delay usage instead of TestWait.Until
- **File**: tests/Privacy/Privacy.Integration/PrivacyStateMachineTests.cs:43,61,63,97,99,127,129,etc.
- **Violation**: Using fixed `Task.Delay()` timeouts instead of polling predicates
- **Fix**: Replace with `TestWait.Until()` calls:
```csharp
// Instead of:
await Task.Delay(500);

// Use:
await TestWait.Until(() => 
{
    var saga = ReadSagaAsync(requestId).Result;
    return saga?.IdentityCompleted == true;
}, TimeSpan.FromSeconds(5), "identity completion");
```
