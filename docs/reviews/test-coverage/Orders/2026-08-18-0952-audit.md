#### HIGH: DbUpdateException 23505 concurrent-duplicate path in CreateOrderCommandHandler
- **For**: `CreateOrderCommand.cs:CreateOrderCommandHandler.Handle` (the `catch (DbUpdateException ex) when (... SqlState == "23505")` block)
- **Type**: Unit
- **Why**: This is the actual concurrency-safety mechanism for duplicate checkout submissions. If it regresses, concurrent duplicate orders throw 500s instead of returning the existing order id.
- **Skeleton**:
```csharp
[Fact]
public async Task Handle_WhenSaveThrowsUniqueViolationOnSagaId_ClearsTrackerAndReturnsExisting()
{
    var command = new CreateOrderCommand(Guid.NewGuid().ToString(), "e@x.com", 1000L, "USD",
        Guid.NewGuid(), "key", new List<CreateOrderLineItem> { new(Guid.NewGuid(), "P", 1, 1000L) });

    var existing = OrderTestHelpers.CreateOrder(sagaId: command.SagaId);

    _orderRepositoryMock.SetupSequence(x => x.GetBySagaIdTrackedAsync(command.SagaId, It.IsAny<CancellationToken>()))
        .ReturnsAsync((Order?)null)   // first check: not there yet
        .ReturnsAsync(existing);      // after conflict: someone else created it

    _orderRepositoryMock.Setup(x => x.AddAsync(It.IsAny<Order>(), It.IsAny<CancellationToken>())).Returns(Task.CompletedTask);
    _eventPublisherMock.Setup(x => x.Publish(It.IsAny<OrderCreatedEvent>(), It.IsAny<CancellationToken>())).Returns(Task.CompletedTask);

    var pgEx = new Npgsql.PostgresException("duplicate key", "ERROR", "ERROR", "23505");
    _orderRepositoryMock.Setup(x => x.SaveChangesAsync(It.IsAny<CancellationToken>()))
        .ThrowsAsync(new DbUpdateException("conflict", pgEx));
    _orderRepositoryMock.Setup(x => x.ClearChangeTracker());

    var result = await _handler.Handle(command, CancellationToken.None);

    Assert.True(result.IsSuccess);
    Assert.Equal(existing.Id, result.Value);
    _orderRepositoryMock.Verify(x => x.ClearChangeTracker(), Times.Once);
}
```

- **Fix**:

```csharp
await Haworks.BuildingBlocks.Testing.TestWait.NotHappens(async () =>

        .Select(o => (OrderStatus?)o.Status).FirstOrDefaultAsync();
    return status == OrderStatus.Expired;
}, TimeSpan.FromMilliseconds(500), because: "terminal order must not transition to Expired");
```
