## Test Optimization Violations

**File**: `tests/CheckoutOrchestrator/CheckoutOrchestrator.Integration/SagaCompensationChaosTests.cs:292`
**Violation**: Uses `builder.ConfigureServices(services => {...})` instead of the mandated `ConfigureTestServices`. Confirmed by contrast — `AuthTests.cs:28`, `CheckoutWebAppFactory.cs:63`, `CheckoutRealTransportFactory.cs:70` all correctly use `ConfigureTestServices`; this is the sole outlier.
**Fix**: `builder.ConfigureTestServices(services => {...})` — `ConfigureServices` runs before the host's own `Startup`/`Program` registrations are finalized and can be silently overridden by them; `ConfigureTestServices` runs after, guaranteeing the test override wins.

**Files**: `SagaFlowsTests.cs:305-311`, `CheckoutSagaEndToEndTests.cs:138-144`, `SagaCompensationChaosTests.cs:233-239`, `PaymentExpiryTests.cs:199-205`
**Violation**: Each file defines its own private `PollUntilAsync` helper built on raw `Task.Delay(250)`, rather than the shared `TestWait.Until()`. Confirmed: `grep -rln 'TestWait' tests/CheckoutOrchestrator` matches **only** compiled `bin/**/Haworks.BuildingBlocks.Testing.xml` doc-comment artifacts — zero real `.cs` source file in this test suite imports/uses `TestWait` despite it being available in `BuildingBlocks.Testing` specifically to replace this pattern.
**Fix**: Delete the four duplicate `PollUntilAsync` implementations; call `TestWait.Until(() => condition, timeout: TimeSpan.FromSeconds(N))` instead, consolidating polling/timeout behavior in one place.

**File**: `tests/CheckoutOrchestrator/CheckoutOrchestrator.Integration/PaymentExpiryTests.cs:128`
**Violation**: A standalone raw `await Task.Delay(TimeSpan.FromSeconds(2))` outside any polling helper — a fixed sleep-and-hope wait, not even the private `PollUntilAsync` pattern used elsewhere in the same file.
**Fix**: Replace with `TestWait.NotHappens(() => condition, TimeSpan.FromSeconds(2))` if the intent is "assert X does NOT happen within 2s", which is the exact use case that helper exists for.

**Files**: `SagaRealTransportTests.cs:72`, `InterceptorWiringTests.cs:73`
**Violation**: Raw unrolled `for` loops with `Task.Delay(1000)`, up to 60 iterations (60s worst-case wall time per test run), instead of a bounded polling helper.
**Fix**: Replace with `TestWait.Until(() => condition, timeout: TimeSpan.FromSeconds(60), pollInterval: TimeSpan.FromMilliseconds(200))` — same worst-case bound, much lower typical latency, and consistent with the rest of the platform's integration suites.
