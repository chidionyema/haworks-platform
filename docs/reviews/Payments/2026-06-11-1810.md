### CRITICAL: Untracked Entities Won't Persist Changes
- **File**: src/Payments/Payments.Application/Commands/Refunds/CreateRefundCommand.cs:36
- **Issue**: Handler fetches payment with `GetByIdAsync()` which returns untracked entities, then calls `payment.RecordRefund()` and expects `SaveChangesAsync()` to persist changes
- **Impact**: Refund amounts may not be recorded in the database, causing data consistency issues and allowing over-refunding

