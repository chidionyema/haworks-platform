### HIGH: Incomplete Dispose Pattern

- **File**: src/Identity/Identity.Infrastructure/Authentication/RotatingJwtSigningKeyRing.cs:366-372
- **Issue**: Dispose method doesn't dispose RSA keys stored in `_entries` collection
- **Impact**: Memory leaks when the service shuts down or the key ring is disposed
- **Fix**: Dispose RSA keys in the Dispose method:
```csharp
public void Dispose()
{
    if (_disposed) return;
    _disposed = true;
    
    _lock.EnterWriteLock();
    try
    {
        foreach (var entry in _entries)
        {
            entry.Key.Rsa?.Dispose();
        }
        _entries.Clear();
    }
    finally
    {
        _lock.ExitWriteLock();
    }
    
    _loopCts?.Dispose();
    _lock.Dispose();
}
```
