- **File**: src/Audit/Audit.Infrastructure/Queries/AuditQueryService.cs:55-59
- **Issue**: Base64 decoding and parsing in `DecodeCursor` has no error handling
- **Impact**: Malformed cursors could cause exceptions, potentially revealing stack traces or causing DoS
- **Fix**: 
```csharp
private static (DateTimeOffset, Guid)? DecodeCursor(string cursor)
{
    try
    {
        var decoded = Encoding.UTF8.GetString(Convert.FromBase64String(cursor));
        var parts = decoded.Split('|');
        if (parts.Length != 2) return null;
        return (DateTimeOffset.Parse(parts[0], CultureInfo.InvariantCulture), Guid.Parse(parts[1]));
    }
    catch { return null; }
}
```
