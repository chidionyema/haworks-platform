## CRITICAL: CDC Source Version Bug

### CRITICAL: Hardcoded Source Version in CDC Processing
- **File**: src/Search/Search.Application/Consumers/IndexableEntityChangedConsumer.cs:126
- **Issue**: CDC events always use `sourceVersion: 1`, while MassTransit events can have any version
- **Impact**: Creates ordering inconsistencies. A CDC event (v1) followed by a MassTransit event (v0) will be skipped, but MassTransit v2+ will overwrite CDC data unpredictably
- **Fix**: Extract actual version from Debezium metadata or use timestamp-based versioning

### CRITICAL: Invalid Category ID Generation in CDC
- **File**: src/Search/Search.Application/Consumers/IndexableEntityChangedConsumer.cs:122
- **Issue**: `categoryId: string.IsNullOrEmpty(categoryId) ? Guid.NewGuid() : Guid.Parse(categoryId)` generates random GUID for null category
- **Impact**: Products get inconsistent, invalid category IDs that don't match any real category
- **Fix**: Use a predefined "uncategorized" category ID or proper null handling
