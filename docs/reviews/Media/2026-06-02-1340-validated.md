## CRITICAL: Manual Transaction Management in MediatR Handlers

### CRITICAL: Violates MassTransit Outbox Pattern 
- **File**: src/Media/Media.Api/Application/CompleteMultipartUpload.cs:74,88
- **Issue**: Manual `BeginTransactionAsync()` in handler that publishes MassTransit events
- **Impact**: Breaks outbox atomicity - events may not be delivered if transaction fails after event publish
- **Confidence**: 10/10
- **Fix**: Remove manual transactions and let MassTransit EF outbox manage transaction lifecycle

```csharp
// REMOVE these manual transactions:
await using var hashTx = await context.Database.BeginTransactionAsync(ct);
await using var tx = await context.Database.BeginTransactionAsync(ct);

// Let MassTransit outbox handle transactions automatically
```

### CRITICAL: Multiple SaveChanges Within Transaction
- **File**: src/Media/Media.Api/Application/CompleteMultipartUpload.cs:92,97
- **Issue**: Two separate `SaveChangesAsync()` calls for atomic state change
- **Impact**: File can be stuck in intermediate state if second save fails
- **Confidence**: 10/10
- **Fix**: Combine state changes before single SaveChanges call

```csharp
// INSTEAD OF:
mediaFile.MarkAsQuarantined();
await context.SaveChangesAsync(ct);
mediaFile.MarkAsActive();
await context.SaveChangesAsync(ct);

// DO:
mediaFile.MarkAsQuarantined();
mediaFile.MarkAsActive();
await context.SaveChangesAsync(ct);
```
