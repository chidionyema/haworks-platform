## CRITICAL: Input Validation Vulnerabilities

### CRITICAL: Generic Object Inputs Bypass Validation
- **File**: src/BffWeb/BffWeb.Api/Controllers/AiController.cs:20,42,65,77
- **Issue**: Controllers use `[FromBody] object body` which bypasses all model validation, allowing arbitrary JSON payloads
- **Impact**: Potential for injection attacks, data corruption, and downstream service failures when malformed data is forwarded
- **Fix**: Replace with strongly-typed DTOs with validation attributes:
```csharp
public sealed record AiSearchRequest
{
    [Required, MaxLength(1000)]
    public required string Query { get; init; }
    
    [Range(1, 100)]
    public int MaxResults { get; init; } = 10;
}

[HttpPost("search")]
public async Task<IActionResult> SemanticSearch([FromBody] AiSearchRequest request, CancellationToken ct = default)
```

### CRITICAL: Missing Rate Limiting on Expensive Operations
- **File**: src/BffWeb/BffWeb.Api/Controllers/AiController.cs:42,77
- **Issue**: AI endpoints (chat, content generation) lack rate limiting despite being computationally expensive
- **Impact**: Service could be overwhelmed by AI request floods, causing denial of service
- **Fix**: Add `[EnableRateLimiting("expensive")]` attribute to AI endpoints

## HIGH: Concurrency and Race Conditions

### HIGH: Unsafe Decimal to Long Conversion
- **File**: src/BffWeb/BffWeb.Api/Controllers/CheckoutController.cs:78,89
- **Issue**: Using `Math.Round` on decimal-to-long conversions without checking for overflow
- **Impact**: Large monetary amounts could overflow, causing incorrect billing or exceptions
- **Fix**: Use checked arithmetic and proper bounds checking:
```csharp
checked {
    var amountCents = (long)Math.Round(body.TotalAmount * 100m, 0, MidpointRounding.AwayFromZero);
    if (amountCents < 0 || amountCents > long.MaxValue / 100)
        return BadRequest("Amount out of valid range");
}
```
